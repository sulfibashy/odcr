# odcr-teradata

The [odcr](https://github.com/sulfibashy/odcr) connector for **Teradata Vantage**.

```bash
pip install odcr-teradata
odcr init my_contracts --adapter teradata
```

This package contains no code: it installs `odcr` together with the teradata driver
(the same as `pip install "odcr[teradata]"`). Documentation: https://sulfibashy.github.io/odcr/
