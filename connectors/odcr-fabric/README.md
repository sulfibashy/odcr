# odcr-fabric

The [odcr](https://github.com/sulfibashy/odcr) connector for **Microsoft Fabric Warehouse**.

```bash
pip install odcr-fabric
odcr init my_contracts --adapter fabric
```

This package contains no code: it installs `odcr` together with the fabric driver
(the same as `pip install "odcr[fabric]"`). Documentation: https://sulfibashy.github.io/odcr/
