# odcr-postgres

The [odcr](https://github.com/sulfibashy/odcr) connector for **PostgreSQL**.

```bash
pip install odcr-postgres
odcr init my_contracts --adapter postgres
```

This package contains no code: it installs `odcr` together with the postgres driver
(the same as `pip install "odcr[postgres]"`). Documentation: https://sulfibashy.github.io/odcr/
