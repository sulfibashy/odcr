# odcr-clickhouse

The [odcr](https://github.com/sulfibashy/odcr) connector for **ClickHouse**.

```bash
pip install odcr-clickhouse
odcr init my_contracts --adapter clickhouse
```

This package contains no code: it installs `odcr` together with the clickhouse driver
(the same as `pip install "odcr[clickhouse]"`). Documentation: https://sulfibashy.github.io/odcr/
