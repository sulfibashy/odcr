# odcr-duckdb

The [odcr](https://github.com/sulfibashy/odcr) connector for **DuckDB**.

```bash
pip install odcr-duckdb
odcr init my_contracts --adapter duckdb
```

This package contains no code: it installs `odcr` together with the duckdb driver
(the same as `pip install "odcr[duckdb]"`). Documentation: https://sulfibashy.github.io/odcr/
