# odcr-saphana

The [odcr](https://github.com/sulfibashy/odcr) connector for **SAP HANA**.

```bash
pip install odcr-saphana
odcr init my_contracts --adapter saphana
```

This package contains no code: it installs `odcr` together with the saphana driver
(the same as `pip install "odcr[saphana]"`). Documentation: https://sulfibashy.github.io/odcr/
