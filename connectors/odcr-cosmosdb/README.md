# odcr-cosmosdb

The [odcr](https://github.com/sulfibashy/odcr) connector for **Azure Cosmos DB (NoSQL)**.

```bash
pip install odcr-cosmosdb
odcr init my_contracts --adapter cosmosdb
```

This package contains no code: it installs `odcr` together with the cosmosdb driver
(the same as `pip install "odcr[cosmosdb]"`). Documentation: https://sulfibashy.github.io/odcr/
