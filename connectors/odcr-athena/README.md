# odcr-athena

The [odcr](https://github.com/sulfibashy/odcr) connector for **Amazon Athena**.

```bash
pip install odcr-athena
odcr init my_contracts --adapter athena
```

This package contains no code: it installs `odcr` together with the athena driver
(the same as `pip install "odcr[athena]"`). Documentation: https://sulfibashy.github.io/odcr/
