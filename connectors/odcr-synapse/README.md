# odcr-synapse

The [odcr](https://github.com/sulfibashy/odcr) connector for **Azure Synapse Analytics**.

```bash
pip install odcr-synapse
odcr init my_contracts --adapter synapse
```

This package contains no code: it installs `odcr` together with the synapse driver
(the same as `pip install "odcr[synapse]"`). Documentation: https://sulfibashy.github.io/odcr/
