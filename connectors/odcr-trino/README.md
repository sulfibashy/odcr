# odcr-trino

The [odcr](https://github.com/sulfibashy/odcr) connector for **Trino / Starburst / Presto**.

```bash
pip install odcr-trino
odcr init my_contracts --adapter trino
```

This package contains no code: it installs `odcr` together with the trino driver
(the same as `pip install "odcr[trino]"`). Documentation: https://sulfibashy.github.io/odcr/
