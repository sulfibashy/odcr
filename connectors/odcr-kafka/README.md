# odcr-kafka

The [odcr](https://github.com/sulfibashy/odcr) connector for **Apache Kafka**.

```bash
pip install odcr-kafka
odcr init my_contracts --adapter kafka
```

This package contains no code: it installs `odcr` together with the kafka driver
(the same as `pip install "odcr[kafka]"`). Documentation: https://sulfibashy.github.io/odcr/
