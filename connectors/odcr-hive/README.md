# odcr-hive

The [odcr](https://github.com/sulfibashy/odcr) connector for **Apache Hive / Spark SQL**.

```bash
pip install odcr-hive
odcr init my_contracts --adapter hive
```

This package contains no code: it installs `odcr` together with the hive driver
(the same as `pip install "odcr[hive]"`). Documentation: https://sulfibashy.github.io/odcr/
