# odcr-impala

The [odcr](https://github.com/sulfibashy/odcr) connector for **Apache Impala**.

```bash
pip install odcr-impala
odcr init my_contracts --adapter impala
```

This package contains no code: it installs `odcr` together with the impala driver
(the same as `pip install "odcr[impala]"`). Documentation: https://sulfibashy.github.io/odcr/
