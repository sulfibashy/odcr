# odcr-databricks

The [odcr](https://github.com/sulfibashy/odcr) connector for **Databricks**.

```bash
pip install odcr-databricks
odcr init my_contracts --adapter databricks
```

This package contains no code: it installs `odcr` together with the databricks driver
(the same as `pip install "odcr[databricks]"`). Documentation: https://sulfibashy.github.io/odcr/
