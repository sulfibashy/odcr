# odcr-mysql

The [odcr](https://github.com/sulfibashy/odcr) connector for **MySQL / MariaDB**.

```bash
pip install odcr-mysql
odcr init my_contracts --adapter mysql
```

This package contains no code: it installs `odcr` together with the mysql driver
(the same as `pip install "odcr[mysql]"`). Documentation: https://sulfibashy.github.io/odcr/
