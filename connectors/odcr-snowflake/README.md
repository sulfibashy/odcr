# odcr-snowflake

The [odcr](https://github.com/sulfibashy/odcr) connector for **Snowflake**.

```bash
pip install odcr-snowflake
odcr init my_contracts --adapter snowflake
```

This package contains no code: it installs `odcr` together with the snowflake driver
(the same as `pip install "odcr[snowflake]"`). Documentation: https://sulfibashy.github.io/odcr/
