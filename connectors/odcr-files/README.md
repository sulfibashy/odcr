# odcr-files

The [odcr](https://github.com/sulfibashy/odcr) connector for **Files: ADLS, S3, GCS, local**.

```bash
pip install odcr-files
odcr init my_contracts --adapter files
```

This package contains no code: it installs `odcr` together with the files driver
(the same as `pip install "odcr[files]"`). Documentation: https://sulfibashy.github.io/odcr/
