# odcr-db2

The [odcr](https://github.com/sulfibashy/odcr) connector for **IBM Db2**.

```bash
pip install odcr-db2
odcr init my_contracts --adapter db2
```

This package contains no code: it installs `odcr` together with the db2 driver
(the same as `pip install "odcr[db2]"`). Documentation: https://sulfibashy.github.io/odcr/
