# odcr-vertica

The [odcr](https://github.com/sulfibashy/odcr) connector for **Vertica**.

```bash
pip install odcr-vertica
odcr init my_contracts --adapter vertica
```

This package contains no code: it installs `odcr` together with the vertica driver
(the same as `pip install "odcr[vertica]"`). Documentation: https://sulfibashy.github.io/odcr/
