# odcr-redshift

The [odcr](https://github.com/sulfibashy/odcr) connector for **Amazon Redshift**.

```bash
pip install odcr-redshift
odcr init my_contracts --adapter redshift
```

This package contains no code: it installs `odcr` together with the redshift driver
(the same as `pip install "odcr[redshift]"`). Documentation: https://sulfibashy.github.io/odcr/
