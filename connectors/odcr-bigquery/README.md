# odcr-bigquery

The [odcr](https://github.com/sulfibashy/odcr) connector for **Google BigQuery**.

```bash
pip install odcr-bigquery
odcr init my_contracts --adapter bigquery
```

This package contains no code: it installs `odcr` together with the bigquery driver
(the same as `pip install "odcr[bigquery]"`). Documentation: https://sulfibashy.github.io/odcr/
