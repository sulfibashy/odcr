# odcr-sqlserver

The [odcr](https://github.com/sulfibashy/odcr) connector for **SQL Server / Azure SQL**.

```bash
pip install odcr-sqlserver
odcr init my_contracts --adapter sqlserver
```

This package contains no code: it installs `odcr` together with the sqlserver driver
(the same as `pip install "odcr[sqlserver]"`). Documentation: https://sulfibashy.github.io/odcr/
