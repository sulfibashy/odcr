# odcr-eventhubs

The [odcr](https://github.com/sulfibashy/odcr) connector for **Azure Event Hubs**.

```bash
pip install odcr-eventhubs
odcr init my_contracts --adapter eventhubs
```

This package contains no code: it installs `odcr` together with the eventhubs driver
(the same as `pip install "odcr[eventhubs]"`). Documentation: https://sulfibashy.github.io/odcr/
