# odcr-oracle

The [odcr](https://github.com/sulfibashy/odcr) connector for **Oracle Database**.

```bash
pip install odcr-oracle
odcr init my_contracts --adapter oracle
```

This package contains no code: it installs `odcr` together with the oracle driver
(the same as `pip install "odcr[oracle]"`). Documentation: https://sulfibashy.github.io/odcr/
