# odcr-mongodb

The [odcr](https://github.com/sulfibashy/odcr) connector for **MongoDB**.

```bash
pip install odcr-mongodb
odcr init my_contracts --adapter mongodb
```

This package contains no code: it installs `odcr` together with the mongodb driver
(the same as `pip install "odcr[mongodb]"`). Documentation: https://sulfibashy.github.io/odcr/
