# odcr-all

The [odcr](https://github.com/sulfibashy/odcr) connector for **every platform**.

```bash
pip install odcr-all
odcr init my_contracts --adapter postgres
```

This package contains no code: it installs `odcr` together with the all driver
(the same as `pip install "odcr[all]"`). Documentation: https://sulfibashy.github.io/odcr/
