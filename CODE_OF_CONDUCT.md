# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment or personal attacks are not tolerated.

Report unacceptable behaviour to the maintainers by opening a private security advisory or by contacting a maintainer directly. Reports are handled confidentially.
